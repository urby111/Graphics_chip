# VGA frame viewer

`main.cpp` is a dependency-free Windows viewer for the 640x480, 12-bit RGB
hex file generated by the Verilator testbench.

From a Visual Studio Developer PowerShell, build it with:

```powershell
cl /std:c++17 /EHsc .\screen\main.cpp user32.lib gdi32.lib /Fe:.\screen\vga_screen.exe
```

Then display a captured frame:

```powershell
.\screen\vga_screen.exe .\verilator\first_frame.hex
```

The window can be resized. Pixels are scaled with nearest-neighbor sampling so
the FPGA output remains crisp.

For the complete point-GPU demo (C camera/object setup -> HDL -> RAM -> VGA):

```powershell
.\verilator\run_gpu_demo.ps1 -View
```

Edit `demo_scene.txt` to change the camera, object, focal length, or vertices.
The script saves the new frame to `verilator/gpu_demo/gpu_frame.hex` and opens
it in this viewer. The older font-capture workflow is unchanged.
